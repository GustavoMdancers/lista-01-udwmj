# Lista 1 - Calculadora Web

Calculadora web simples desenvolvida em HTML, CSS e JavaScript para a atividade Lista 1 da disciplina UDWMJ.

## Funcionalidades

- Adição, subtração, multiplicação e divisão.
- Limpeza do display pelo botão `C`.
- Validação de divisão por zero.
- Registro no console do navegador sempre que um botão é pressionado.
- Interface responsiva dentro de uma calculadora centralizada.

## Tecnologias

- HTML5
- CSS3
- JavaScript

O projeto não utiliza bibliotecas, frameworks ou dependências externas.


## Como executar

1. Clone este repositório ou baixe os arquivos.
2. Abra o arquivo `lista1.html` em um navegador.

Também é possível usar a extensão **Live Server** no VS Code para iniciar um servidor local.

## Como usar

1. Pressione os botões numéricos para informar o primeiro valor.
2. Escolha um operador: `+`, `-`, `*` ou `/`.
3. Informe o segundo valor.
4. Pressione `=` para visualizar o resultado.
5. Pressione `C` para limpar o display e começar novamente.

Para visualizar os registros dos botões pressionados, abra as ferramentas de desenvolvedor do navegador e acesse a aba **Console**.
